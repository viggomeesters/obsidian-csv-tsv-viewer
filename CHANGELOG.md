# Changelog

All notable changes to CSV TSV Viewer are documented here.

## 0.1.0 - 2026-06-07

- Initial public release.
- Add read-only `.csv` and `.tsv` file view.
- Add table view with sticky header, row numbers, search/filter, and row/column/delimiter summary.
- Add source view with line numbers and lightweight delimiter highlighting.
- Add comma/semicolon detection for CSV and tab delimiter for TSV.
- Add parse warnings for parser errors, uneven rows, byte order marks, and large-file render caps.
